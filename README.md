# เว็บขายคอร์ส The Bossnoi

## เปิดดูบนเครื่อง
1. ติดตั้ง Node.js (เวอร์ชัน 20 ขึ้นไป) จาก https://nodejs.org
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์ `npm install` (ทำครั้งแรกครั้งเดียว)
3. พิมพ์ `npm run dev`
4. เปิดเบราว์เซอร์ไปที่ http://localhost:3000/courses/ccm

## แก้ข้อมูลคอร์ส / เพิ่มคอร์สใหม่
ข้อมูลทุกคอร์สอยู่ที่ `data/courses.ts` ไฟล์เดียว
- แก้ข้อความ: แก้ในไฟล์นั้นได้เลย
- เพิ่มคอร์ส: คัดลอกก้อนคอร์ส CCM แล้วเปลี่ยน `slug` (จะได้หน้า `/courses/<slug>`)
- ข้อความที่ยังไม่มีข้อมูล ให้เขียน `[ระบุ: ...]` หน้าเว็บจะไฮไลต์สีส้มไว้

## รูปภาพ
วางรูปไว้ใน `public/images/` แล้วใส่ชื่อไฟล์ใน `data/courses.ts` เช่น `image: "/images/ccm/hero.jpg"`

## Key / รหัสลับ
คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ค่าจริง ไฟล์ `.env.local` จะไม่ถูกส่งขึ้น GitHub
